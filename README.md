# Skeleton 08 · Pruebas de voz Prescouting TV

Repositorio separado de la web y de los servicios de Prescouting. Contiene únicamente tres demostraciones de voz y su reproductor móvil, sin bases de datos, credenciales ni código de producción. Sintetizados localmente a partir de la misma identidad vocal, con un ritmo más ágil y recuperación de inteligibilidad.

Estas muestras no son locuciones definitivas.
